DebtSense — AI Code Health & Bug-Risk Predictor

A Python ML pipeline that predicts which files in a codebase are most likely to have future bugs, using nothing but git commit history.

  • Mines commit history with PyDriller (4,600+ commits analyzed)
  • Engineers features like code churn, author count, and commit frequency
  • Trains a RandomForest classifier with a temporal train/test split — features from past commits, labels from future bug-fixes, to avoid data leakage
  • Outputs a color-coded CLI report ranking the riskiest files
